Fetch, combine, and save data

Work through each example on its own. Every step has a separate button and output; the final challenge combines the ideas.

STEP 1

Fetch local JSON

Click to request the local file, parse its JSON, and turn each item into a visible list entry. It also fills the favorite menu in the final challenge.

    Why these lines? 
    // fetch() asks the browser for the local JSON file.
const response = await fetch("assets/data/data.json");

// HTTP errors do not automatically reject fetch(), so check response.ok.
if (!response.ok) throw new Error("Could not load local JSON");

// .json() reads the response body and converts JSON text into JS values.
const choices = await response.json();

    STEP 3

    Store and retrieve a small object

    This example has its own sample object and storage key, so it works without running Step 2 or the final challenge. 

    Stored data will appear here.
    Why stringify and parse? 
    // Storage can keep strings, not JavaScript objects.
const sampleObject = { name: "Garfield", favorite: "lasagna" };
const jsonText = JSON.stringify(sampleObject);
sessionStorage.setItem("teachingUserData", jsonText);

// getItem() returns text. JSON.parse() converts that text to an object.
const savedText = sessionStorage.getItem("teachingUserData");
const savedObject = JSON.parse(savedText);

    STEP 4

    Fetch data from a public API

    This request is independent of the local JSON and user form examples. It displays the image URL returned in the API's message property.

    Why inspect the API response? 
    const response = await fetch(apiUrl);
if (!response.ok) throw new Error("API request failed");

// Dog CEO returns an object; message contains the image URL.
